🎓 EDU Dashboard: Student Performance & Enrollment Analytics
📌 Short Description / Purpose

The EDU Dashboard is an interactive Power BI visualization designed to analyze student enrollment, academic performance, tuition fees, and subject selection trends across multiple cities and grade levels. It helps educational institutions, administrators, and analysts gain actionable insights into student demographics, academic engagement, and financial metrics through dynamic and visually rich reporting.

🛠️ Tech Stack

The dashboard was built using the following tools and technologies:

📊 Power BI Desktop – Used for creating interactive visualizations and dashboard layouts.
📂 Power Query – Applied for data cleaning, transformation, and preprocessing.
🧠 DAX (Data Analysis Expressions) – Used to create calculated measures, KPIs, and dynamic aggregations.
🔗 Data Modeling – Relationships established between student, subject, city, and grade-level datasets.
📁 File Formats – .pbix for dashboard development and .png for dashboard preview/export.

✨ Features / Highlights
📍 Business Problem

Educational institutions often struggle to monitor and compare:

Student enrollment trends
Academic performance across grade levels
Subject popularity
Tuition fee contribution
Regional student distribution

Raw educational data can be difficult to interpret quickly, especially when analyzing multiple dimensions simultaneously.

🎯 Goal of the Dashboard

The primary goal of the EDU Dashboard is to:

Provide a centralized academic analytics platform
Monitor student performance and enrollment patterns
Compare cities and grade levels interactively
Track tuition fee contribution by subjects
Support data-driven academic and administrative decisions
